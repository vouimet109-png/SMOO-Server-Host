Help

Run your own SMOO server in 6 steps. It runs on your computer and you control it from this site.

  1. Install Python

    Download Python 3.8 or newer from python.org. On Windows, tick “Add Python to PATH” during the install.

  2. Get the SMOO server

    Download SmoOnlineServer (open source) from its GitHub releases and unzip it in a folder. Run it once so it creates its files, then close it.

  3. Download the agent

    It is a single readable file. It only writes settings.json, starts or stops the server and its tunnel, and reports if you are online. It never runs commands sent by the site.

    Download agent.py

  4. Get your server key

    Create a server on this site, open it with Manage, and copy the key from the Connection tab. Keep it secret.

  5. Run the agent

    Open a terminal in the folder of agent.py and run:

    python agent.py

    The first time, it asks for the key and the path of the server program. Leave the window open: settings you change on the site are applied within seconds.

    To change the key or the path later, run:

    python agent.py --setup

  6. Hide your IP address

    Nothing to do: the agent opens a free tunnel for you (using bore, open source), so your IP stays hidden and you open no port on your router. The address your friends use appears on your server card once the agent runs. It changes each time you restart the agent.
